# SOMA Schedule Helper 개인정보처리방침 초안

이 문서는 Chrome Web Store 등록 시 사용할 수 있도록 정리한 초안입니다.
실제 배포 전에는 운영 주체명, 문의 이메일, 게시 URL을 본인 정보로 교체해 공개 URL로 호스팅해 주세요.

## 1. 수집 및 처리하는 정보

SOMA Schedule Helper는 다음 정보에 접근할 수 있습니다.

- 사용자가 직접 선택한 Google Calendar 일정 정보
- 확장프로그램 동작에 필요한 설정값
- 소프트웨어 마에스트로 특강 페이지에서 사용자가 보고 있는 일정 정보

## 2. 정보 사용 목적

확장프로그램은 아래 목적에 한해 정보를 사용합니다.

- 소마 특강 일정과 Google Calendar 일정의 겹침 여부 비교
- 사용자가 신청한 특강 일정을 Google Calendar에 추가, 수정, 삭제
- 옵션 페이지에서 저장한 사용자 설정 반영

## 3. 정보 전송 및 저장

- Google Calendar 데이터는 Google Calendar API 호출을 위해서만 사용됩니다.
- 사용자의 일정 정보는 확장프로그램 기능 수행 외 목적으로 판매하거나 제3자에게 제공하지 않습니다.
- 사용자 설정과 일정 매핑 정보는 Chrome Extension 저장소에 저장될 수 있습니다.
- 별도의 자체 서버로 데이터를 전송하지 않습니다.

## 4. 데이터 보관

- 사용자 설정은 사용자가 확장프로그램을 삭제하거나 설정을 변경할 때까지 브라우저 저장소에 남아 있을 수 있습니다.
- Google Calendar의 일정 생성, 수정, 삭제 결과는 사용자의 Google 계정에 반영됩니다.

## 5. 사용자 선택권

- 사용자는 확장프로그램 삭제로 저장된 로컬 데이터를 제거할 수 있습니다.
- 사용자는 Google 계정 권한 관리 페이지에서 Calendar 권한을 철회할 수 있습니다.
