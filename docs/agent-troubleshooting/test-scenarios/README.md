# 테스트 시나리오 개요

각 테스트는 실제 Calendar 검증 모드를 기준으로 작성한다. 기존 `mock/mock-env.js` 기반 전체 목업 모드는 DOM 구조와 UI 흐름의 빠른 확인에만 사용한다.

## 문서 구성

- [Calendar 동기화](calendar-sync.md): 신청 상태 특강 누락, 취소 상태 특강 잔존, 동일 특강의 신청/취소 이력 공존
- [신청/취소 액션](registration-actions.md): 상세 신청, 상세 취소, 목록 패널 취소, 접수내역 취소, 24시간 이내 취소 불가
- [목록 필터](list-filters.md): 사이트 기본 필터와 확장 날짜/겹침 필터의 교집합 검증

## 공통 작성 형식

각 시나리오는 아래 형식을 사용한다.

- 목적: 검증하려는 동작과 실패했을 때 의심할 영역
- 준비: 필요한 fixture, SoMA 목업 응답, Calendar 사전 상태
- 실행: 사용자가 수행하거나 에이전트가 자동화할 절차
- 기대 결과: UI, Calendar, 특강-캘린더 연결 정보, console output에서 확인할 결과
