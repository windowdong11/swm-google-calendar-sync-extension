# 목록 필터

## 사이트 기본 필터와 확장 필터 교집합

목적: 사이트 기본 필터와 확장 날짜/겹침 필터가 순서와 관계없이 함께 적용되는지 확인한다.

준비:

- 전체/접수중/마감 기본 필터 fixture를 준비한다.
- 날짜 범위 안팎의 특강을 준비한다.
- 겹침, 바로 이어짐, 겹치지 않음, 시간 확인 필요 상태를 만들 수 있는 Calendar 일정을 준비한다.

실행:

1. 전체/접수중/마감 중 하나를 먼저 적용한다.
2. 날짜 범위와 겹침 필터를 적용한다.
3. 최종 목록을 기록한다.
4. 같은 조건에서 날짜 범위와 겹침 필터를 먼저 적용한다.
5. 전체/접수중/마감 필터를 나중에 적용한다.
6. 두 순서의 최종 결과를 비교한다.

기대 결과:

- 두 순서의 최종 결과가 동일하다.
- 최종 목록은 사이트 기본 필터와 확장 필터 조건의 교집합이다.
- 페이지 이동 또는 기본 필터 submit 이후에도 날짜 범위가 유지된다.
