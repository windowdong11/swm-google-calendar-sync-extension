SOMA Schedule Helper 설정

Google Calendar 연결

일정 비교나 동기화를 처음 사용할 때 Google Calendar 권한 허용 창이 열립니다.

이 인증 방식은 현재 Google Chrome에서 가장 안정적으로 동작합니다. Arc 같은 비Chrome Chromium 브라우저에서는 Google OAuth가 실패할 수 있습니다.

배포 / 개발용 정보

현재 확장 프로그램 ID: 확인 중...

  1. Google Cloud Console에서 OAuth Client를 Chrome Extension 타입으로 생성
  2. 위 확장 프로그램 ID를 item ID로 등록
  3. 배포 ZIP 생성 시 node scripts/build-release.mjs --oauth-client-id=... 로 client ID를 주입
